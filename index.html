CoinDCX

A listing desk run by an AI agent, approved by a person

The agent prepares each token-listing pass. Deterministic checks confirm the exact contract and screen for sell-blocks, freeze or confiscation rights and punitive taxes. A person approves every production write after a dry run, and each write is read back and saved as an audit receipt. Each of four listing incidents became a permanent guard.

Hands-on review went from 4–5 hours a day to about one, by my estimate.

CoinDCX

Reading the numbers before trusting them

When the trading fee went up in steps, revenue rose and the headline said it worked. Splitting by trader segment showed the heaviest 1% of traders made over half of each month’s volume, and they had cheaper venues to move to. I recommended holdout tests before any future fee change. Elsewhere I found order times stored in local time but labelled UTC, which had put a peak-hours plan several hours off.

Segment splits, cohort checks and a corrected time basis, written up as reusable SQL.

Own project

TsundereSQL

An anime visual novel that is also a full SQL course: 224 graded problems, run in the browser on DuckDB. Every answer is graded against hidden datasets the player never sees, so a query that only fits the sample fails. A read-only guard mirrors DuckDB’s own parser and held up to 50,000 fuzzed queries with no bypass. When an answer is wrong, the checker reruns one-edit variants of it on the data and shows the one to three rows that caused the miss.

Free demo on Steam, about 2,700 wishlists, around 14,000 automated tests.
